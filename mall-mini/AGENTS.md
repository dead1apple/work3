# mall-mini development instructions

- This directory contains the Vue 3 uni-app consumer mini program for the mall backend.
- Keep API paths aligned with the backend contract and the `feature/frontend-init` web implementation.
- Preserve the existing compact JD-inspired visual language: red actions, white content surfaces, light gray page backgrounds, and touch-friendly controls.
- Do not compile, build, preview, launch, or run this project. Do not start a development server or invoke HBuilderX, uni-app, npm, or platform build commands. The user will compile and run the mini program manually.
- Static source inspection is allowed when checking changes.
