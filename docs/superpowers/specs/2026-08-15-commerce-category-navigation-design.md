# 商城分类导航与中文排版修复设计

## 目标

修复首页与分类页之间的分类数据和导航断链，使用户点击任何展示出的分类都能进入由真实分类 ID 筛选的商品列表；同时改善中文标题字距，移除首页商品卡片中容易误解的加号控件，并增加分类页可浏览的品类数量。

## 根因

- 首页“发现好物”使用十个硬编码名称作为商品关键词查询。关键词并不是分类筛选条件，只有“运动”碰巧命中商品名称，因此其余入口经常为空。
- 分类页细分品类的目标路由被写成 `home`，而首页不读取 `categoryId`，所以点击后只是回到首页。
- 首页轮播大标题和区块标题使用负字距。负字距适合部分拉丁字体，但会让连续汉字明显挤压。
- 首页商品卡片的加号按钮执行“查看详情”，与图形表达的“加入购物车”含义不一致，且与整张卡片的点击行为重复。
- 分类页侧栏只展示分类树的一级节点。后端当前只有四个一级节点，但树中仍有更多可直接筛选商品的细分分类。

## 分类数据模型

分类树仍由 `getCategoryTree()` 提供，并统一转换为包含 `id`、`name`、`children` 的前端结构。

新增纯函数从分类树中生成两类数据：

- “可购买分类”：优先选择没有子节点的叶子分类；若树中叶子不足十个，再按树的自然顺序补充非叶子分类，按 ID 去重。
- “可浏览分类”：按树的自然顺序展开全部一级和细分分类，同时保留层级信息，供分类页导航展示。

首页最多展示十个真实分类。分类名称和 ID 均来自接口，不再维护容易失效的固定名称或别名映射。

## 页面行为

### 首页

- 首页加载时并行请求商品列表和分类树，分别维护加载结果；分类请求失败不影响轮播与推荐商品展示。
- “发现好物”展示最多十个真实分类，点击后进入命名路由 `products`，查询参数为 `categoryId=<id>`。
- 分类树为空或请求失败时展示明确的分类空状态，不回退到会产生无结果的硬编码入口。
- “为你推荐”商品卡片继续由整张卡片进入详情页，删除右下角加号按钮，价格区域自然对齐。

### 分类页

- 左侧或移动端导航展示展开后的全部真实分类，并通过缩进或层级样式区分一级分类和细分分类。
- 选择一级分类时，右侧展示其直接子分类，并聚合这些子分类的推荐商品。
- 选择叶子分类时，右侧将该分类作为当前细分品类，直接按其 ID 查询推荐商品；页面不出现无意义的“暂无细分品类”死端。
- 点击任一细分品类进入 `products` 路由，并携带真实 `categoryId`；商品卡片仍进入 `product-detail`。
- 并行获取多个子分类商品时使用可容错的聚合方式：单个子分类请求失败不清空其他已成功结果；全部失败时才显示错误反馈。

## 中文排版与视觉调整

- 中文大标题和区块标题不再使用负字距，默认采用 `letter-spacing: normal`；较大的轮播标题可使用轻微正字距，但不超过现有排版节奏所需范围。
- 英文眉题保留较宽字距，与中文标题分别设置规则。
- 删除加号后不引入新的按钮或依赖；商品卡片的焦点、回车进入详情和悬停反馈保持不变。
- 桌面端与移动端继续沿用现有响应式断点和 Element Plus 组件体系。

## 状态与错误处理

- 分类树加载中显示骨架或占位状态。
- 分类树为空时显示“暂时没有可浏览的分类”。
- 商品筛选结果为空时由商品列表页保留现有空状态和清除筛选入口。
- 分类页聚合商品时去重并限制展示数量，避免同一商品重复出现。
- API 异常继续通过 `ElMessage` 提示，且不把一次局部失败误报成整个页面不可用。

## 测试与验收

- 单元测试覆盖叶子分类优先、数量上限、ID 去重、全树展开及层级信息。
- 源码回归测试覆盖首页和分类页均使用 `products` 路由与 `categoryId`，且首页不存在加号按钮。
- 样式回归测试覆盖中文标题不再使用负字距，英文眉题字距保持独立。
- 运行完整测试套件和生产构建。
- 在桌面和窄屏下检查首页十个入口、分类页展开导航、细分品类跳转、卡片价格布局及键盘进入详情行为。

## 范围

- 不新增或修改后端接口，不虚构分类或商品数据。
- 不实现首页快捷加入购物车。
- 不重做商城整体视觉风格，只修复本次涉及的导航、分类可见性、中文字距和商品卡片控件。
