# 分类页设计

## 目标

将占位的分类页替换为仿京东的左右联动页面：左侧展示一级分类，右侧展示该一级分类下的二级分类和推荐商品。

## 数据与交互

- 首次调用 `getCategoryTree()`，从返回树中提取一级分类及其二级分类，默认选择第一项。
- 后端按一级分类 ID 查询商品会返回空列表，因此选中一级分类时会并行调用其各二级分类的 `getProductList({ categoryId, page: 1, size: 8 })`，去重后展示最多八个推荐商品。
- 二级分类跳转至 `/home?categoryId=<id>`；商品跳转至已有的 `/product/:id` 详情路由。
- 接口加载期间显示骨架屏，商品列表为空时显示空状态；异常使用 `ElMessage.error`。

## 页面与适配

- 桌面端为固定宽度左侧分类导航加右侧内容区。
- 小屏幕下左侧导航变为可横向滚动的顶部分类栏，内容网格缩减列数。
- 二级分类使用图标与文字宫格；推荐商品使用可响应式换列的商品卡片网格。

## 复用与范围

- 复用现有 `getCategoryTree`、`getProductList`，无需新增 API 封装。
- 只替换 `src/views/CategoryView.vue`，并增加纯数据转换与页面状态的单元测试。
